# Explore Medan

Website tugas mahasiswa menggunakan:
- HTML
- Tailwind CSS via CDN
- CSS tambahan
- JavaScript

Fitur:
1. Hero section
2. Navbar
3. 10 destinasi
4. Filter kategori
5. Search destinasi
6. Top Destination
7. Gallery 8 gambar
8. Modal gallery
9. Form pertanyaan
10. Validasi nama dan pesan
11. Animasi hover card
